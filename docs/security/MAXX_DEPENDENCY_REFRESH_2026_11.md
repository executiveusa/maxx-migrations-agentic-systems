# November 2026 production dependency remediation

This isolated security PR is a dependency-only companion to Crown & Core draft PR #39, not a production release.

| Package | Existing lock | Target |
| --- | --- | --- |
| next | 16.3.3 | 16.4.5 |
| zod | 3.25.76 | 4.6.7 (breaking API: must test all schemas) |
| sharp | 0.35.4 | 0.35.5 |

sharp and source-map-js are transitive npm overrides. These values are pinned to independently published fixes. Do not change the deployment target or add runtime tools. The lockfile generated by GitHub Actions must be reviewed at the resulting commit. No merge before npm ci, lint, typecheck, unit tests, npm audit --omit=dev --audit-level=high, and full Next build pass.

The one-time push workflow regenerates only the lockfile using npm install --package-lock-only --ignore-scripts, verifies package versions, commits only the lockfile to this isolated branch, and does not run untrusted lifecycle scripts with a repository write credential. Remove the generator workflow before merge. After review, cherry-pick the exact package + lockfile into PR #39. Rollback: revert only this dependency update.

Next 16.3.6 was insufficient for the October 2026 advisories; the isolated npm audit on the previous lock failed, recommending 16.4.5. The new lock is regenerated and audited before merging. See https://github.com/advisories/GHSA-673q-mjm6-r5xr.

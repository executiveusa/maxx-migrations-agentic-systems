# 05 — Data Schema Spec

## TypeScript domain types

`lib/types/*.ts` — one file per domain (organizations, contacts, pipeline,
forms, workflows, community, courses, social, imports, telephony,
migrations, agents, billing, integrations, audit), re-exported from
`lib/types/crm.ts`.

## Zod validation schemas

`lib/validation/*.ts` — `contact.ts`, `opportunity.ts`, `form.ts`,
`workflow.ts`, `community.ts`, `course.ts`, `social.ts`, `ghl-import.ts`,
`missed-call.ts`, `migration-job.ts`, `agent-policy.ts`,
`integration-connection.ts`, plus the pre-existing `migration-audit.ts`.
Every API route that accepts a body validates it with the matching schema
before touching the store.

## Supabase schema

`apps/maxx-web/supabase/migrations/20260101000000_maxx_crm_core.sql`
defines all 45 tables from the spec (organizations, organization_members,
profiles, contacts, contact_tags, pipelines, pipeline_stages,
opportunities, tasks, forms, form_fields, form_submissions, workflows,
workflow_steps, workflow_runs, communities, community_members,
community_posts, community_comments, community_reactions,
direct_message_threads, direct_messages, courses, course_modules,
course_lessons, course_enrollments, lesson_progress, leaderboard_events,
leaderboard_scores, social_accounts, social_posts, social_publish_jobs,
import_jobs, import_records, import_errors, phone_numbers, call_events,
missed_call_events, mctb_rules, sms_messages, sms_opt_outs,
migration_jobs, migration_pages, migration_assets, ai_agents,
agent_sessions, model_usage, integration_connections, audit_logs,
billing_customers, billing_events).

Every tenant-owned table has `organization_id`, `created_at`,
`updated_at`, RLS enabled, and a single `"org access"` policy generated by
a `do $$ ... $$` block iterating the full table list — driven by
`is_org_member(organization_id)`, a `security definer` function checking
`organization_members`. No table ships with a permissive `using (true)`
policy.

## Seed data

`lib/mock-data/*.ts` provides realistic seed records for every domain,
themed around one demo organization (Riverside Mutual Aid Kitchen) plus
five illustrative example organizations used in Community/marketing copy.

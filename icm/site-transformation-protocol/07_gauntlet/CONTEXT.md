# 07 — GAUNTLET

## Purpose
Judge the real rendered site against a named, fetchable, comparable quality bar rather than against the builder's intent.

## Inputs
- deployed preview or reproducible local render
- approved wireframes/design system
- named quality bar
- required viewport list

## Process
Capture the real reference and our real output at equivalent viewports. Break judgment into independently improvable pieces: hero, type, spacing, navigation, media scale, proof, offer/program presentation, story, CTA behavior, mobile, interaction, accessibility. Use a separate harsh critic/fresh context where the environment supports it. The critic chooses which is stronger and names the single largest remaining gap. Iterate until the site holds its own against the bar or the owner stops the loop.

## Required MACS viewports
- 375×812
- 390×844
- 768×1024
- 1440×900
- 1920×1080

## Outputs
- `GAUNTLET_REPORT.md`
- screenshot/evidence set
- remaining-gap ledger
- explicit pass/fail

## Evidence
Actual screenshots/renders, browser behavior, accessibility evidence, performance measurements where declared.

## Human/authority check
A builder cannot self-approve its own release. Owner/architect accepts the final visual/product judgment.

## Exit condition
No unresolved critical visual/usability/accessibility gap remains and the named comparison was performed against the real reference, not a remembered description.

# CONTEXT — client workspace router

**One ICM grammar:** `01_orient → 02_plan → 03_work → 04_verify → 05_release → 06_learn`. These are the canonical MAXX execution stages; the numbered client folders below are the existing onboarding protocol.

| Request | Load |
|---|---|
| Company identity, consent, systems, source-of-truth inventory | `01_intake/CONTEXT.md` |
| Imported ChatGPT/Claude files, graph, wiki, Obsidian projection | `02_normalize/CONTEXT.md` and `_shared/SECOND_BRAIN.md` |
| Tenant boundary, Composio connections, sandbox and model keys | `03_isolate/CONTEXT.md` |
| Plan, risk, approval, idempotency, action execution | `04_approve/CONTEXT.md` |
| Acceptance, receipts, costs, rollback, backup/restore | `05_prove/CONTEXT.md` and `_shared/COST_POLICY.md` |
| Reset, Momentum, Scale or Launch workflow | `06_transform/CONTEXT.md` and `_shared/OFFER_PLAYBOOKS.md` |
| Existing/open-source repository gap | `_shared/REPO_DISCOVERY.md` |
| Model/provider failover, Instinct bridge, Paperclip/Hermes, Composio | `_shared/CONTRACTS.md` |
| Navigation and graph | `GRAPH.md`, `graph.json` |
| Current evidence | `working-state/STATUS.md` |

**One home per fact.** PostgreSQL/approved source systems own operational truth. The ICM graph points to it. Markdown/Obsidian is an inspectable projection, not an unreviewed autonomous source of facts.

**First pilot:** choose one consented business and one repeated job near money. Never assume any named prospect has authorized data ingestion or agent action.

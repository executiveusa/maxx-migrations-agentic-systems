# 02 — Normalize: portable company brain

**Inputs:** consented source manifests and bounded, private uploads.

**Process:** scan, parse, deduplicate, classify and extract source-linked facts/entities/edges. Keep immutable originals in encrypted object storage. Reconcile conflicts and create review candidates. Use `../_shared/SECOND_BRAIN.md`.

**Outputs:** tenant-scoped canonical records and provenance graph; Obsidian Markdown projection; optional regenerable wiki/vector index.

**Human gate:** owner/authorized reviewer promotes material claims; model inferences remain labeled.

**Exit proof:** source checksums, retrieval citations, conflict report, rejected secret leaks and at least one verified answer grounded in client data.

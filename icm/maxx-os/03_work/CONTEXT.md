# 03_work — execute the bounded slice

## Inputs

- approved plan from `02_plan`
- exact code/data/context required
- applicable security and authority rules

## Process

1. Make the smallest coherent change that satisfies the plan.
2. Keep implementation complexity backstage.
3. Preserve existing behavior outside the slice.
4. Record what changed.
5. Stop before any action that crosses a human authority gate.

## Outputs

Working artifacts, code, configuration, drafts, or prepared actions plus a change record.

## Human check

Only where the plan identified a real authority gate or where new material risk appears.

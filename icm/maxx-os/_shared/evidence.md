# MAXX Evidence Standard

## Evidence states

`PROPOSED -> BUILT -> TESTED -> VERIFIED -> ADOPTED -> VALUABLE`

Never skip states in wording.

## Minimum proof for meaningful work

Record:

- outcome;
- baseline;
- exact change;
- test or observation;
- evidence location;
- owner;
- authority/approval state;
- rollback;
- current evidence state.

## Motion rule

Documentation, mocks, routes, and builds are not enough to prove a cross-system path works.

Motion means:

`surface -> handler -> transport -> canonical owner -> observable result -> evidence`

## Release rule

No production-success claim without deployed/runtime evidence at the revision tested.

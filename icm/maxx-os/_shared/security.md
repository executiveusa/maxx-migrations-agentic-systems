# MAXX Security and Sovereignty

## Never put secrets in ICM.

ICM may store only non-secret references, ownership, purpose, policy, and rotation state.

## Human gates

Explicit approval is required immediately before consequential actions involving:

- money;
- contracts/legal commitments;
- credentials;
- sensitive data;
- public claims or consequential sends;
- destructive production changes;
- security/privacy/payment controls;
- irreversible migration.

## Isolation

Resolve authenticated actor and organization scope for every client action. Do not mix customer context, memory, data, or credentials.

## Sovereignty

Prefer owner-controlled code, domain, data, infrastructure configuration, context, workflows, analytics, and exportability.

## Rollback

Consequential technical changes require a practical rollback path before execution.

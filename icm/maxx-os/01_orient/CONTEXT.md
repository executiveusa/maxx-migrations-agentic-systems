# 01_orient — understand reality before acting

## Inputs

- root `CONTEXT.md`
- `../_shared/product-principles.md`
- current repo/code/deployment/business state
- only task-relevant canonical context

## Process

1. State MODE, OUTCOME, TARGET, CONSTRAINTS, PROOF, COMMERCIAL VALUE, AUTHORITY, ROLLBACK.
2. Identify the canonical owner of the truth involved.
3. Inspect current reality before proposing changes.
4. Separate fact, inference, hypothesis, decision, and evidence.
5. Find the smallest real problem worth solving.

## Outputs

Create or update an orient artifact containing the current state, target, constraints, owner, and evidence gaps.

## Human check

Confirm the target and any material facts that cannot be independently verified.

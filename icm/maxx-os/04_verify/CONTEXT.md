# 04_verify — prove the outcome

## Inputs

- outputs from `03_work`
- acceptance criteria from `02_plan`
- `../_shared/evidence.md`

## Process

1. Run deterministic checks.
2. Test the actual user path when user-facing.
3. Test the actual transport when cross-system.
4. Inspect mobile/accessibility/security where relevant.
5. Capture evidence at the exact revision/deployment.
6. Report failures truthfully.

## Outputs

Verification receipt with current evidence state and unresolved blockers.

## Human check

Decide whether evidence is sufficient for release when judgment, brand, relationships, or risk are involved.

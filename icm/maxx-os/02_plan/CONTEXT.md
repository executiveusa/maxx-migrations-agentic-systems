# 02_plan — choose the smallest useful intervention

## Inputs

- approved output from `01_orient`
- relevant files from `../_shared/`
- only the specialized protocol needed for this job

## Process

1. Prefer reduction before addition.
2. Reuse existing systems before creating new ones.
3. Define one verifiable slice.
4. Define acceptance criteria and proof.
5. Define authority gates and rollback.
6. Reject work that adds complexity without a measurable owner/customer outcome.

## Outputs

A bounded plan/spec that a builder can execute without guessing.

## Human check

Approve brand-defining, costly, irreversible, public, or strategically consequential choices.
